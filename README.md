# LMS SMAN 2 Padalarang

Repositori Sistem Informasi Learning Management System (LMS) SMA Negeri 2 Padalarang.

## Struktur Direktori

- `model/` : Implementasi kode Java untuk **UML Class Diagram** (11 kelas entitas dan relasinya).
- `sequence/` : Implementasi kode Java untuk **UML Sequence Diagram** (alur simulasi interaksi use case).
- `SOFTWARE REQUIREMENT SPESIFICATION_KELOMPOK 6.pdf` : Dokumen Spesifikasi Kebutuhan Perangkat Lunak (SRS).
- `SofwareDesignDocument_kelompok6.pdf` : Dokumen Desain Perangkat Lunak (SDD).
